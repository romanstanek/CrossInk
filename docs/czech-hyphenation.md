# Czech hyphenation

Czech EPUBs use the existing language-aware Liang hyphenation engine when the
reader's Hyphenation setting is enabled. Accepted publication language tags are
`cs` (including regional tags such as `cs-CZ`), `ces`, and `cze`, case-insensitively.
Legacy publisher metadata `cz` is also accepted. Minimum prefix and suffix lengths
are two letters, matching the upstream Czech implementation. Accented Czech
letters work in both precomposed and decomposed Unicode, with break offsets kept
in the source text's UTF-8 bytes.

The serialized trie is from
[typst/hypher](https://github.com/typst/hypher/tree/d81cc506416bffef2a75ee2dc969d4b41bc36613),
revision `d81cc506416bffef2a75ee2dc969d4b41bc36613`, `tries/cs.bin`.
Its source is `patterns/hyph-cs-sojka.tex`, version 2021-07-21, by Petr Sojka and
Ondrej Sojka. The patterns' MIT notice is preserved in
`lib/Epub/Epub/hyphenation/CZECH-PATTERNS-LICENSE.txt`.

SHA-256 of the 40,726-byte binary:
`1f7cb32555583658b8bc6daa35d213e856f28b69d47f44322eae2e11c2037557`.

To reproduce the checked-in header, download `tries/cs.bin` at that revision and run:

```sh
python scripts/generate_hyphenation_trie.py \
  --input build/cs.bin \
  --output lib/Epub/Epub/hyphenation/generated/hyph-cs.trie.h
```

`scripts/update_hyphenation.sh` includes Czech when refreshing all upstream tries.
The generated byte array is constexpr data stored in flash; no additional pattern
table is allocated on the heap. Cache version 84 invalidates old page layouts.

For hardware verification, enable Hyphenation, open a Czech EPUB, and check that
long words split with visible hyphens at the right margin. Check accented words
such as `příliš`, `průvodce`, and `československý`, then reopen an English EPUB to
verify language switching. Try both left alignment and justification; the latter
should fill each line while using hyphenation to limit stretched spaces.
